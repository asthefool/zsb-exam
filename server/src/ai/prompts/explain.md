# 输出结构约束（必须包含以下三个小节，使用中文）
## 一、错因分析
比对考生答案与正确答案，说明错在哪里、可能的知识误区。
## 二、解题思路与步骤
给出本题的完整解题过程。
## 三、知识点提示
总结本题考查的知识点，并给出一条复习建议。

# 边界指令
仅就本题讲解，不扩展与本题无关的内容；不要使用「作为AI」等表述。
